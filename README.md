# Pickuply

Mobile-first pickup, delivery, and hauling marketplace. Progressive Web App built with Next.js.

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

The dev server runs at [http://localhost:3000](http://localhost:3000).

Copy `.env.local.example` to `.env.local` when later steps need credentials. Do not commit real keys. No live services are connected yet.
